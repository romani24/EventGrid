# EventGrid

Bold editorial event discovery experience with category filters, search, saved events and an interactive ticket selection flow.

## Tech stack

- React 19
- TypeScript
- Vite
- Lucide Icons

## Feature-driven structure

- `src/app` — page composition and global styles
- `src/features/discovery` — event data, search, filters and saved events
- `src/features/tickets` — ticket tier, quantity and confirmation flow
- `src/shared` — reusable navigation components

## Run locally

```bash
npm install
npm run dev
```

All events, venues, prices and tickets are fictional demo content. No payment is collected.
